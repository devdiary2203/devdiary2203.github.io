Spring là một framework cung cấp bộ công cụ để phát triển ứng dụng java, bao gồm các chức năng được cài đặt sẵn như dependency injection, các module Spring JDBC, Spring MVC, Spring AOP, Spring ORM, Spring Test. Các module này giúp rút ngắn thời gian phát triển ứng dụng và nâng cao hiệu năng
